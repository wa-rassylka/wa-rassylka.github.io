# Ватсап рассылка

WhatsApp Web-те бір батырмамен көп адамға хабарлама жіберу — кеңейтусіз (bookmarklet).

- `index.html` — басты бет, «📨 Рассылка» бетбелгісін осыдан сүйреп аласыз
- `panel.js` — WhatsApp Web ішінде ашылатын панель (бетбелгі коды)
- `juz40.html` / `juz40.js` — JUZ40 тапсырмағандарын тауып, панельге жіберетін бет
- `reyting.html` / `reyting.js` / `reyting-core.js` — JUZ40 апталық жалпы рейтинг, СТ рейтинг және отчет жолын есептеп, Google Sheets-ке түстерімен көшіретін бет
